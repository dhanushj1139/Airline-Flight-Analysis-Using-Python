# Airline Flight Analysis Using Python

## Overview

This project focuses on analyzing airline flight data using Python to identify patterns in flight operations, ticket pricing, flight duration, and departure-time sessions.

The dataset contains **15,769 rows and 12 columns**. The project covers data inspection, data cleaning, outlier detection and treatment, exploratory data analysis, and visualization using **Pandas, NumPy, Matplotlib, and Seaborn**.

## Dataset

- Rows: 15,769
- Columns: 12
- Domain: Airline Flight Data
- File Format: CSV

## Objectives

- Analyze airline flight data using Python.
- Perform data cleaning and preprocessing.
- Identify and handle outliers in price and duration.
- Analyze flight counts across different departure sessions.
- Compare total ticket amounts across airlines.
- Analyze ticket amounts across different departure sessions.
- Generate meaningful visualizations and insights.
